## Зоны

### [ ] 1. Resize зоны только через ПКМ
- **Сделано.** Обычный режим:
  - зону больше нельзя выделить для растягивания;
  - зажатая ЛКМ на зоне начинает обычное выделение рамкой.

  Режим растягивания:
  - ПКМ по зоне → «Resize» включает режим, у зоны появляются 8 ручек;
  - клик мимо зоны (ЛКМ или ПКМ) или любая обычная клавиша выключает режим. Ctrl, Shift, Alt и Win не выключают (поправлено в 1.3.3);
  - **Shift + край**: противоположные стороны расходятся симметрично, центр остаётся на месте;
  - **Shift + угол**: весь прямоугольник растёт вокруг центра;
  - каждое растягивание — отдельный шаг Undo. Если выйти из режима и нажать Ctrl+Z, режим включается снова и последнее растягивание отменяется.
- **Как проверить:**
  1. Нарисуй зону, внутри поставь 2 ноды. Зажми ЛКМ на пустом месте зоны и протяни рамку через ноды: должны выделиться ноды, а не зона.
  2. ПКМ по зоне → Resize: появились ручки.
  3. Зажми Shift, потом возьми правую ручку и тяни: левая сторона уезжает в противоположную сторону на столько же. Режим не сбросился от Shift.
  4. Shift + угол: зона растёт во все стороны от центра.
  5. Кликни мимо: ручки пропали. Нажми Ctrl+Z: ручки вернулись, размер откатился на один шаг.
- **Проверено мной:** да, всё выше (симметрия, выход, Ctrl+Z, модификаторы не сбрасывают).

### [ ] 11. Кисть зон рисует поверх нод
- **Сделано.** В режиме кисти (Z) ноды не мешают: мазок можно начинать и вести прямо по ноде, а сама нода при этом не выделяется.
- **Как проверить:** Z → кисть, начни мазок на ноде и проведи через неё.
- **Проверено мной:** да (зона появилась, нода не выделилась).

### [ ] 20. Ctrl+Alt при переносе зоны — без сетки
- **Сделано.** В режиме переноса зоны: Ctrl — зона двигается вместе с нодами по сетке (как было), Ctrl+Alt — вместе с нодами, но без привязки к сетке.
- **Как проверить:** включи сетку (магнит). Перенеси зону с Ctrl: ноды прыгают по шагу сетки. Затем с Ctrl+Alt: двигаются плавно.
- **Проверено мной:** нет, только тесты агента. **Проверь обязательно.**

### [ ] 10. Секундомер (Stopwatch)
- **Сделано.**
  - **Переключатель.** В шапке ноды Time две «пилюли»: **Time | Stopwatch**. Активная яркая, неактивная серая. По умолчанию выбран Time.
  - **Экран Stopwatch.** Сверху по центру большой счётчик: дни, часы, минуты, секунды. Под ним список **Mode** из 5 режимов (как на твоей картинке) и галочка **Since project created**:

    | Режим | Как считает | Галочка «Since project created» |
    |---|---|---|
    | Since project created | с момента создания проекта | **включена и не снимается** (зелёная рамка) |
    | Since node created | с момента создания ноды | неактивна |
    | While hive window is focused | только пока окно hive в фокусе | **можно включить**: тогда считается фокус с создания проекта, а не ноды |
    | While hive runs | пока hive запущен, включая трей | **можно включить**, так же |
    | On stop/resume command | только между Resume и Stop | неактивна |

  - **Кнопка Stop/Resume** есть **только** в режиме «On stop/resume command», как ты решил.
  - **Поле Conditions** показывает ноды активации, подключённые к Time сильной линией. Пока это Random Choice. Каждое её срабатывание **переключает Stop/Resume**, как ты решил. Будущие Button и Timer подключатся так же.
  - **Сохранение.** Значения переживают перезапуск. У старых проектов «дата создания проекта» — самая ранняя дата создания ноды.
- **Как проверить:**
  1. Q → Time, в шапке нажми Stopwatch. Пилюля стала яркой, Time посерел.
  2. Mode = Since project created: счётчик идёт, галочка стоит и не снимается.
  3. Since node created: счётчик с нуля (от создания ноды), галочка неактивна.
  4. While hive window is focused: переключись в другое окно — счётчик стоит. Вернись — идёт. Поставь галочку — число прыгает на «фокус с создания проекта».
  5. On stop/resume command: появилась кнопка. Resume → идёт, Stop → стоит.
  6. Random Choice → сильная линия → Time (в режиме stop/resume). Сделай выбор в Random Choice: секундомер переключился. Ctrl+Z выбора — секундомер **не** переключается.
  7. Закрой и открой hive: значения на месте.
- **Проверено мной:** частично. Пилюли, счётчик, режим «Since project created» и заблокированная галочка — да. Остальные режимы и Random Choice — только тесты агента. **Проверь пункты 3–7.**

## Message

### [ ] 5. Task, связанный с Message
- **Сделано.** Если Task связан с Message сильной линией в любую сторону, в карточке показывается текст задачи, а заголовок — её имя. Go to ведёт к задаче. Если задач несколько, берётся первая по порядку на доске.
- **Как проверить:** Time → Message, Task — Message. Дождись срабатывания: в карточке текст Task. Нажми Go to: выделилась задача.
- **Проверено мной:** да.

### [ ] 6. Importance для Message
- **Сделано.** Importance можно подключить к Message линией или вставить в неё, как в заметку. Importance задачи, связанной с Message, тоже учитывается. Берётся максимальный уровень:
  - **рамка карточки** окрашивается в цвет Importance;
  - **звуков** (если включён Sound): basic или без Importance — 1, medium — 2, important — 3, immediately — 4, absolute — 5.
- **Как проверить:**
  1. Вставь Importance «important» в Message: рамка карточки красная.
  2. Включи Sound: при срабатывании 3 сигнала. Поменяй на absolute: 5.
  3. Убери Importance у Message, поставь на связанную Task: цвет берётся от задачи.
- **Проверено мной:** цвет рамки — да. **Звук — только в программе**, его количество проверь на слух.
