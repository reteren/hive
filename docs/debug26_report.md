## Проект как одна папка (замена Obsidian)

### 1. Всё, что есть в проекте, лежит в его папке

Структура проекта: `board.json` + `notes/*.md` + `attachments/` + `drawing/`.

- **Любой перетащенный файл копируется в проект.** Это `json`, `txt`, `md`, `gif`, `png`, `pdf`, аудио, `zip`, `exe`, `docx` и всё остальное. Раньше «прочие» файлы создавали ноду Source со ссылкой на файл снаружи проекта. Теперь нода ссылается на копию внутри (`source.file`) и открывает файл оттуда.
- **Читаемые имена:** `attachments/photo.png`, `photo (2).png` вместо хешей.
  - Конфликты имён без учёта регистра обрабатываются как в Windows, включая кириллицу.
  - Запрещённые имена Windows (`CON`, `NUL`…) и недопустимые символы обрабатываются.
- **Миграция старых проектов при открытии.** Хеш-имена переименовываются, порядок такой:
  1. записать журнал `.hive/attachment-migration.json`;
  2. скопировать файлы под новыми именами;
  3. переписать ссылки в `board.json`, корзине, архиве и картинках внутри заметок;
  4. удалить старые файлы.

  Если процесс прервётся, при следующем открытии миграция доделается. Занятый файл (например, открытое видео) не мешает открытию: его удаление повторится в следующий раз.
- **Видео больше 20 МБ** не копируется, нода хранит путь к нему (`media.externalPath`). На другом компьютере, где файла нет, нода показывает название и «File not found» с путём, без плеера и без превью.
- **Export zip** включает `attachments/` и не включает внешние видео. Import zip открывает проект со всеми файлами.
- **Бэкапы**, сделанные до миграции, после неё по-прежнему восстанавливаются вместе с медиа.

## Меню слева сверху (вместо «project (main)»)

### Кнопка File
1. **New…**: новый проект, `Ctrl+Shift+N`.
2. **Open…**: открыть проект, `Ctrl+O`.
3. **Open recent ›**: последние 10 проектов, папки и zip, новые сверху.
   - Пропавший проект отмечается «(missing)».
   - Внизу есть «Clear recent».
   - Открытие zip из списка — это импорт этого архива.
4. **Save**: сохранить сейчас, `Ctrl+S`.
5. **Import zip…**
6. **Export zip…**: полный экспорт проекта в zip.
7. **Quit**: сохраняет правки и выходит полностью, вместе с иконкой в трее.

### Кнопка Edit
1. **Undo** / **Redo**.
2. **Open undo history**: включает кнопку Undo log справа сверху, `Ctrl+Alt+Z`. По умолчанию кнопка скрыта, сворачивается и разворачивается как раньше.
3. **Search**: бинд показан в меню, `Ctrl+T`. Кнопка Search справа сверху удалена.
4. **Command search**: то же самое, `F3`.
5. **Task**: включает кнопку Tasks справа, `Shift+Alt+T`. По умолчанию скрыта, на кнопке есть подсказка с биндом.
6. **Trash**: включает кнопку Trash справа, новый бинд `Alt+D`.
7. **Object list**: включает кнопку Objects справа, `Alt+O`, с подсказкой.

У включённых пунктов стоит галочка, видимость кнопок запоминается.

**Шорткаты пунктов 3, 6, 7, 8 из твоего списка** (Undo history, Task, Trash, Object list) больше не открывают панели справа. Они открывают окно по центру экрана немного сверху, как Search и Command search. В окне всё то же, что в панели. Esc, клик снаружи или повторное нажатие шортката закрывают окно.

Меню открывается кликом. Между File и Edit можно переключаться наведением, есть стрелки, Esc и клик снаружи. Меню отображается поверх кнопки Beacons и панелей.

1. **Home view и Reset zoom** убраны из центра верхней панели. Сами команды и их бинды остались.

3. **Delete permanently без вопроса.** Теперь появляется тёмное подтверждение: «Delete … permanently? This cannot be undone.». Фокус на Cancel, Enter удаляет, Esc отменяет. Так же работает Empty trash в корзине и в настройках.

5. **Нода Task в Q-меню** стоит сразу под Note. Создаёт обычную ноду, уже отмеченную как задача, это один шаг Undo. Mark as task остался.
6. **Красный треугольник в Q-меню** — это была play-стрелка у иконки YouTube, удалена. Ты подтвердил, что это он.
7. **Mark as task** теперь только у обычной ноды и текстовых файлов (`json`, `txt`, `md` и т. п.). У ноды, которая уже задача, «Unmark» сохранён.
