# hive

Пространственная доска для заметок, задач и связанных материалов. Сейчас здесь описание проекта и план разработки, **работающего приложения ещё нет**.

## Куда смотреть

- [NODES.md](NODES.md) — все выбранные ноды, модули и их готовность; источник ответа «какие ноды ещё остались?».
- [ROADMAP.md](ROADMAP.md) — небольшие этапы, проверка результата и границы каждого этапа.
- [FOLLOWUP_QUESTIONS.md](FOLLOWUP_QUESTIONS.md) — заполненные уточнения, учтённые в roadmap. Не требуется проходить анкету заново; оставшиеся развилки привязаны к конкретным этапам.
- [LATER.md](LATER.md) — «напомни, что мы отложили»: сомнения, дальние планы и отклонённое отдельно.
- [QUESTIONS_AND_IDEAS.md](QUESTIONS_AND_IDEAS.md) — твои ответы и собственные идеи; сохранены без изменений.
- [hive.md](hive.md) — первоначальный замысел. Более поздние ответы и уточнения важнее противоречащих им старых формулировок.

Название приложения — **hive**, не Mastermind. Стартовое ядро называется ME.

23 сентября 2026: roadmap пересобран по новым ответам. Все этапы и ноды пока **не начаты**. Код, каркас приложения и зависимости не создавались. После команды начать берём только R0; у каждого подпункта есть видимый результат и проверка.

## Первая цель разработки

Только окно, поле, камера, сетка и базовые инструменты с кнопками и биндами. Без технических нод, рисования, картинок и этажей. После этого — обычные заметки; затем Task, Importance, Purpose и плюсы/минусы. IF и этажи остаются в дальнем ящике.

Дизайн развивается по живым прототипам с сильной опорой на выбранные принципы Blender. Не требуется заранее держать весь интерфейс в голове или реализовывать весь roadmap одним промптом.

Исходные ориентиры: Windows, английский интерфейс, Rust/Tauri; редактор — с опорой на твой [MarkNote](https://github.com/reteren/marknote). Команды сборки и точные зависимости появятся после создания кода и проверки запуска, а не как вымышленные инструкции сейчас.

Материалы в `discovery/` — рабочие разборы агентов, не дополнительные задания тебе и не более высокий источник требований.
